# タカハシタカユキのポートフォリオ

## Webフォント

`npm run dev` と `npm run build` は、`src/` 内のページやスクリプトなどに含まれる文字をもとに、Gen Interface JP の配信用 WOFF2 を生成します。本文やカード名を編集するたびに配信用ファイルを作り直す作業は不要です。原本に収録されていない文字は端末のフォントで表示します。

`assets/fonts/` には [Gen Interface JP v0.8.0](https://github.com/yamatoiizuka/gen-interface-jp/releases/tag/v0.8.0) の Light・Regular・Medium・Bold の TTF を、文字を削らず WOFF2 に変換した原本を置いています。ライセンスは [SIL Open Font License](public/fonts/licenses/GenInterfaceJP-OFL.txt) です。
